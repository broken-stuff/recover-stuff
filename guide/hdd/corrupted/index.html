💽 Hard drive (internal HDD) · 🧩 Corrupted / RAW / asks to format

Fix a Corrupted or Unreadable Hard Drive

Corrupted means the drive's records of where each file is are damaged, often after a power cut, a bad shutdown or failing parts. The files are often still there. Do not run repair tools on the original first, because they can change your data.

3/5 · Take care
Success odds: Medium

The drive may be weakening, and repair tools such as CHKDSK on the original can change data before you have a copy.

✋ Stop! Don't do this first

  • Do not run CHKDSK, fsck or Disk Utility's First Aid on the original before copying your data. Repairs can rewrite data.
  • Do not click Format when Windows says the drive needs to be formatted.
  • Do not install recovery software onto the affected drive, and do not save recovered files back to it.

Your steps

0 of 7 done
  1. Show me how
    1. Windows: close the drive's folders, then right-click the drive in File Explorer and choose Eject. Mac: drag it to the Trash or click the Eject button in Finder.
    2. Then shut down. If the drive is making clicking or grinding noises, read our clicking guide instead.
  2. Show me how
    1. Windows: install and open CrystalDiskInfo, then look at Health Status. Mac or Linux: in a terminal run smartctl -a /dev/sdX.
    2. Reallocated, Pending or Uncorrectable sector counts above zero mean the disk surface is wearing out. Caution or Bad means the drive is failing.

    Guide: How to check if a drive is healthy (SMART)

  3. Show me how
    1. Check the damaged drive's size in File Explorer or Disk Utility.
    2. Use a different drive with at least that much free space.
  4. Show me how
    1. Boot a live USB if needed (our guide shows how), then open a terminal and run lsblk to identify both drives.
    2. Run sudo ddrescue -n /dev/sdX /mnt/backup/disk.img /mnt/backup/disk.map, where sdX is the damaged drive. Always type the failing drive first and the empty destination second. If you swap them, the copy erases your data.
    3. Keep the map file so you can stop and resume. HDDSuperClone is an alternative on Linux.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  5. Show me how
    1. If you have space, copy the image file so you have a spare.
    2. Run sudo testdisk disk.img and follow its menus to rebuild the partition or list the files.
    3. Copy what you find to a different drive.

    Guide: How to use TestDisk to copy files off a drive

  6. Show me how
    1. Run sudo photorec disk.img and choose the image file.
    2. Pick the file types you want, then a destination folder on a different drive, and press c.

    Guide: How to use PhotoRec to recover photos and files

  7. Show me how
    1. Open a few files of each type to check they work.
    2. Keep a second copy on another drive or in cloud storage.
Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Should I run CHKDSK to fix it?

Not first. It can rewrite damaged data. Make an image of the drive, then repair or recover from that copy.

What is a disk image?

It is an exact copy of everything on the drive, saved as a file or onto another drive. It lets you try recovery over and over without risking the original.

Why does it say the drive is RAW?

The computer cannot read the drive's file system, which is its way of organising files, usually because of damage. The data is often still there and TestDisk may restore it.
