💽 Hard drive (internal HDD) · 🗑️ Deleted files

Recover Deleted Files From an Internal Hard Drive

When you delete a file, the computer usually just marks its space as free. The data stays on the disk until something new is written over it. The sooner you stop using the drive, the better your chances.

1/5 · Safe to DIY
Success odds: High

If the drive is healthy, recovery only reads data, as long as you save results to a different drive.

✋ Stop! Don't do this first

  • Stop saving, downloading, installing or browsing on this drive right now. New data can overwrite your deleted files.
  • Do not install recovery software onto the affected drive. Install it on a different drive or run it from a USB stick.
  • Do not save recovered files back to the same drive. Always pick a different drive.

🧑‍🔧 When to call a pro

If the drive starts making odd noises, disappears, or the files are very valuable and recovery fails, stop and talk to a professional before trying more.

Questions people ask

Can I get back files I emptied from the Recycle Bin?

Often yes, because emptying the bin only frees the space, so stop using the drive right away. Some newer SMR drives clear freed space like an SSD does, which lowers the odds.

Why did my recovered files lose their names?

PhotoRec finds files by their content, not by the file table, so names and folders are not saved. TestDisk can sometimes keep names if the file table is still intact.

Is it a problem that I kept using the computer after deleting?

It lowers the odds a bit, because new data may land on the freed space. Stop now and recover what is left.
