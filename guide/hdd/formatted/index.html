💽 Hard drive (internal HDD) · 🧹 Accidentally formatted

Recover Files From a Formatted Hard Drive

A quick format wipes the drive's table of contents but leaves most of your data in place, so recovery is often possible. A full format on Windows Vista or newer writes zeros over everything, and that data is gone for good.

2/5 · Low risk
Success odds: Varies

Recovery software only reads the drive, but saving anything new onto it can destroy what is left.

✋ Stop! Don't do this first

  • Do not copy, save or install anything onto the formatted drive. New data overwrites what you want back.
  • Do not format it again, and do not reinstall Windows or macOS onto it.
  • Do not install recovery software onto the formatted drive. Use a different drive.

Your steps

0 of 6 done
  1. Show me how
    1. Think back: did the format finish in seconds or a few minutes? That was a quick format. Did it run for hours? That was a full format.
    2. On Windows, the Format window had a Quick Format tick box. If it was ticked, it was quick. On a Mac, Erase is normally quick unless you chose Security Options and moved the slider toward Most Secure.
    3. If you are not sure, carry on. Scanning is safe, and the results will tell you.
  2. Show me how
    1. Do not copy files onto it, install programs, or start a new backup.
    2. If it is your main drive and the computer is running, shut it down: Windows Start, Power, Shut down; Mac Apple menu, Shut Down.
  3. Show me how
    1. Shut down, unplug the drive and connect it to a second computer as an extra drive, using a USB adapter or dock if needed.
    2. Or boot from a live USB (a USB stick that runs its own small copy of Linux without installing anything).
    3. Get a different drive with enough free space for everything you want back.

    Guide: How to make a Linux live USB (step by step)

  4. Show me how
    1. In a terminal, type sudo testdisk and press Enter (on a live USB, first type sudo apt install testdisk). On Windows, run testdisk_win.exe as administrator.
    2. Choose Create, pick the drive, accept the partition type it suggests, then choose Analyse and Quick Search.
    3. If it finds your old partition, press p to list its files and check they look right. Copy what you need with c to a folder on your second drive. Do not choose Write: it changes the drive itself.

    Guide: How to use TestDisk to copy files off a driveGuide: Data recovery glossary for beginners

  5. Show me how
    1. Type sudo photorec (Windows: run photorec_win.exe as administrator) and pick the drive.
    2. Choose the Whole disk line, then Search, then the file system type Other (for FAT, NTFS, exFAT) or ext2/ext3/ext4 for Linux drives, then Whole.
    3. Pick a folder on your second drive and press c. This can take hours for a big drive.

    Guide: How to use PhotoRec to recover photos and files

  6. Show me how
    1. Open a few files of each type. Photos should show the whole picture, and documents should open without errors.
    2. If many files are blank or damaged, the data was probably overwritten. Stop there rather than running more tools.
    3. Sort the recovered files into folders and make a backup of the good ones right away.
Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Can I recover data after a full format?

On Windows Vista and newer, no. A full format writes zeros over the whole disk. A quick format is a different story and is often recoverable.

Did reinstalling Windows destroy my files?

It overwrote part of the drive, so some files are lost. Others may still be there, so stop using it and scan it from another computer with PhotoRec.

Will I get my folders and file names back?

Sometimes with TestDisk. With PhotoRec, files usually come back with generic names and are sorted by type.
