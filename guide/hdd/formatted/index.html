💽 Hard drive (internal HDD) · 🧹 Accidentally formatted

Recover Files From a Formatted Hard Drive

A quick format wipes the drive's table of contents but leaves most of your data in place, so recovery is often possible. A full format on modern Windows (Vista and later) writes zeros over everything, and that data is gone for good.

2/5 · Low risk
Success odds: Varies

Software recovery only reads from the drive, but writing anything new to it can destroy what is left.

✋ Stop! Don't do this first

  • Do not copy, save or install anything onto the formatted drive. New data overwrites what you want back.
  • Do not format it again, and do not reinstall the operating system on it.
  • Do not install recovery software onto the formatted drive. Use a different drive.

🧑‍🔧 When to call a pro

If the drive is making noises, is not detected, or the data is critical and software scans fail, stop and consult a professional.

Questions people ask

Can I recover data after a full format?

On Windows Vista and newer, a full format writes zeros over the disk, so the data is gone. A quick format is a very different story and is often recoverable.

Did reinstalling Windows destroy my files?

It overwrote part of the drive, so some files are lost. Others may still be there, so stop using it and scan it from another computer with PhotoRec.

Will I get my folders and file names back?

Sometimes with TestDisk. With PhotoRec, files usually come back with generic names and are sorted by type.
