SD / microSD card · Encrypted or locked

Recover Data from an Encrypted SD or microSD Card

Some phones, cameras and apps encrypt memory cards, tying them to a device, a password or a key (a secret code that unlocks the data). If you do not have the key, recovery is not realistically possible. If you do, the data can usually be unlocked on the right device.

3/5 · Take care
Success odds: Varies

Resetting the phone, formatting the card or tapping 'Forget' on it in Android settings can delete the key and make the data unreadable for good.

✋ Stop! Don't do this first

  • Do not format the card or reset the phone or camera it was used in.
  • Do not use tools that claim to crack or guess passwords.
  • Do not install recovery software onto the card.

Your steps

0 of 6 done
  1. Show me how
    1. Think about where the card was used: an Android phone that encrypted it, a camera app, or a program like VeraCrypt or BitLocker To Go.
    2. Plug it into a Windows computer. A padlock on the drive icon means BitLocker To Go.
    3. A card the computer says is unreadable and which an Android phone encrypted must be unlocked in that phone.
    4. Write down what you find.

    Guide: Data recovery glossary for beginners

  2. Show me how
    1. Do not sell, wipe or reset the phone the card was used in.
    2. Keep its lock-screen PIN or password handy.
    3. Do not tap Forget or Format on the card in the phone's storage settings.
  3. Show me how
    1. Search your password manager, notes and email for the card, the app name or 'recovery key'.
    2. BitLocker: go to aka.ms/myrecoverykey (it opens account.microsoft.com/devices/recoverykey) on any device and sign in with the Microsoft account you used.
    3. Check printouts and files saved earlier.
  4. Show me how
    1. Android: put the card back in the original phone and enter the lock-screen PIN or password.
    2. BitLocker To Go: double-click the card in File Explorer, click More options > Enter recovery key and click Unlock.
    3. VeraCrypt: open the app, click Select Device, pick the card, click Mount and enter the password.
    4. Copy the files to another drive.
  5. Show me how
    1. You need a second drive with free space at least as big as the SD card. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the SD card's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). A card in a built-in slot shows as mmcblk0. Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the SD card.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/card.img /media/ubuntu/DEST/card.map. Replace sdX with the SD card's name (a card in a built-in card slot shows as mmcblk0 instead, so you would type /dev/mmcblk0) and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the SD card (the source), the second is where the copy goes. Swapping them erases the SD card.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  6. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/card.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Point TestDisk or PhotoRec at the unlocked card or its image, choose Analyse and Quick Search, and copy files to another drive.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Can I read an encrypted SD card without the key?

Realistically no. Modern encryption with a strong password cannot be guessed or bypassed, so be wary of anyone who says otherwise.

Will a new phone read my encrypted card?

Often not, if the key was tied to the old phone. Keep the old device until you have copied your files.
