SD / microSD card · Corrupted / RAW / asks to format

Fix a Corrupted SD or microSD Card Without Losing Photos

A card can become corrupted when removed during a write, when power dies, or when it wears out. Its file system (the index of what is stored where) is damaged, so the camera may call it unreadable or RAW. The photos are often still there. Making a copy before any repair keeps your options open.

3/5 · Take care
Success odds: Medium

Formatting, chkdsk or the camera's 'repair' prompts can overwrite the information needed to get your files back.

✋ Stop! Don't do this first

  • Do not click Format when the camera or computer asks to.
  • Do not run chkdsk or any 'repair' prompt before making an image.
  • Do not take more photos with the card.

Your steps

0 of 6 done
  1. Show me how
    1. Turn the camera or phone off.
    2. Take the card out. A microSD card may need a pin or fingernail.
    3. If any message offered to format or fix it, do not accept it.
  2. Show me how
    1. Take the card out of the camera or phone. A microSD card sits in a small slot or tray, so use a pin or fingernail if needed.
    2. Full-size SD card or a microSD adapter: slide the small lock switch on the side down to the Lock position, before you plug it in. A plain microSD card has no switch.
    3. Put the card in a USB card reader and plug it into the computer. Some readers ignore the lock, so still do not save anything to the card.
    4. If a window offers to format the card, click Cancel. Never click Format.
  3. Show me how
    1. You need a second drive with free space at least as big as the SD card. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the SD card's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). A card in a built-in slot shows as mmcblk0. Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the SD card.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/card.img /media/ubuntu/DEST/card.map. Replace sdX with the SD card's name (a card in a built-in card slot shows as mmcblk0 instead, so you would type /dev/mmcblk0) and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the SD card (the source), the second is where the copy goes. Swapping them erases the SD card.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

  4. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/card.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Choose Analyse, then Quick Search. If your folders appear, press p to browse and c to copy files to a different drive. Do not choose Write.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

  5. Show me how
    1. Open PhotoRec (a free tool that searches for file contents instead of file names; it comes with TestDisk). Windows: in the unzipped TestDisk folder, right-click qphotorec_win.exe and choose Run as administrator (this version has buttons). Linux live USB: type sudo apt install testdisk if you have not yet, then sudo photorec /media/ubuntu/DEST/card.img to search your image. Mac: brew install testdisk, then sudo photorec. The text version uses the arrow keys and Enter.
    2. Pick the drive or image from the list (text version: then choose Proceed), then the partition, or the Whole disk line if unsure. When asked for the file system, pick Other (the window version calls it FAT/NTFS/HFS+/ReiserFS/...) unless it was a Linux drive (ext2/ext3/ext4). Choose Free for deleted files, or Whole for formatted, RAW or damaged drives.
    3. Click File Formats and untick types you do not need to save time. Some names differ from the file endings: keep jpg and png for photos, mov for MP4 and MOV videos, pdf, and zip for DOCX and XLSX. Text version: choose File Opt before Search, press s to untick everything, tick types with the Space bar, then press q to go back. Skipping this is also fine.
    4. Choose where to save results: a folder on a different drive, never the SD card itself. Window version: click Browse. Text version: after Search it shows a list of folders; move to /media/ubuntu/DEST with the arrow keys and Enter, then press C.
    5. Window version: click Search. It can take hours. Leave the computer on until it says it has finished.

  6. Show me how
    1. Recover only to your computer or another external disk.
    2. Open a few photos to confirm they work.
    3. Do not reuse the card until everything is safe.

Questions people ask

Why does my camera say the card needs formatting?

The file system is damaged or unreadable. Your photos may still be on the card, so do not format yet.

Is it safe to run chkdsk on a corrupted card?

Not before you have a copy. Chkdsk changes the card and can delete data it cannot fix.
