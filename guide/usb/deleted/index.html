🔌 USB flash drive · 🗑️ Deleted files

Recover Deleted Files from a USB Flash Drive

When you delete a file from a USB drive, the drive usually just forgets where the file was. The data itself stays until new files overwrite it. Most flash drives do not use TRIM (a feature that tells a drive to wipe deleted space), so recovery chances are often good if you act quickly. Every new file you save lowers the odds.

2/5 · Low risk
Success odds: High

Scanning from a copy is safe, but saving anything new to the drive can overwrite the deleted files for good.

✋ Stop! Don't do this first

  • Stop saving or copying anything to the USB drive. New files can overwrite the deleted ones.
  • Do not install recovery software onto the USB drive for the same reason.
  • Do not format the drive, even if Windows asks you to. Formatting makes recovery harder.

Your steps

0 of 7 done
  1. Show me how
    1. Windows: click the small arrow in the taskbar near the clock, click the USB icon and choose Eject. Mac: drag the drive icon to the Trash (it turns into an Eject button) or right-click it > Eject.
    2. Wait for the message that it is safe to remove, then pull it out.
    3. Put it somewhere safe and do not use it again until recovery is done.
  2. Show me how
    1. Windows: open the Recycle Bin on the desktop, look for your file, right-click it and choose Restore.
    2. Mac: click the Trash in the Dock, right-click the file and choose Put Back.
    3. Check cloud services (OneDrive, iCloud, Google Drive) and email attachments for copies.
    4. Check your phone, other computers and old backup drives.
  3. Show me how
    1. You need a second drive with free space at least as big as the USB drive. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the USB drive's name. Linux: type lsblk and match it by size (it looks like /dev/sdb). Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -d /dev/sdX /mnt/backup/usbdrive.img /mnt/backup/map.log replacing sdX and the folder with yours. The first path is the USB drive (the source), the second is where the copy goes. Swapping them erases the USB drive.
    6. Wait until it says it is finished. Keep the map.log file: it lets you stop and resume. Work only on an image file from now on.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  4. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: unzip the download from cgsecurity.org and double-click testdisk_win.exe. Mac or Linux: in Terminal type sudo testdisk.
    2. If you made an image, open it by typing testdisk image.img (Windows: run this in Command Prompt from the TestDisk folder). Otherwise choose the drive from the list with the arrow keys and press Enter.
    3. Choose Create (log file), then pick the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Choose your partition, press Advanced, then Undelete. Deleted files show in red. Press c to copy a file, then pick a folder on a different drive.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it yet.

    Guide: How to use TestDisk to copy files off a driveGuide: Data recovery glossary for beginners

  5. Show me how
    1. Open PhotoRec (a free tool that searches for file contents instead of file names). Windows: unzip the TestDisk download and double-click qphotorec_win.exe for the click-and-type window. Mac or Linux: in Terminal type sudo photorec.
    2. Choose your image file (or the drive if you have no image) at the top of the window or in the list, then pick Whole disk or the biggest partition.
    3. Click File Formats and untick types you do not need (for example keep only JPG, PNG, MP4, DOCX) to save time. Skipping this is also fine.
    4. Click Browse and choose a folder on a folder on your computer or a different drive, never the USB drive itself, never on the drive you are scanning.
    5. Click Search (terminal: press C). It can take hours. Leave the computer on.

    Guide: How to use PhotoRec to recover photos and files

  6. Show me how
    1. When the tool asks where to save, choose a folder on your computer's main drive or another external drive.
    2. Make sure it has at least as much free space as the USB drive.
    3. Never pick the USB drive or its image file as the destination.
    4. Check the free space first. Windows: open This PC. Mac: right-click the drive > Get Info.
  7. Show me how
    1. Open the folder PhotoRec or TestDisk saved into. PhotoRec makes folders called recup_dir.1, recup_dir.2 and so on with numbered file names.
    2. Windows: click Sort by > Type in File Explorer. Mac: click View > as List, then click the Kind column.
    3. Double-click a few files of each type. A photo that shows, a document that opens or a video that plays means it worked.
    4. Files that will not open, or look blank or all gray, are damaged or already erased. Open a few more before deciding.
Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Why can I recover deleted files from a flash drive?

Deleting usually just removes the file's entry from the list. The data stays on the drive until something new is written over it.

Do deleted USB files go to the Recycle Bin?

On Windows, usually not: they are removed right away. A Mac may keep them in the Trash until you empty it, so check there.
