🔌 USB flash drive · 🔐 Encrypted or locked

Recover Data from an Encrypted USB Drive

Encrypted USB drives scramble data so it cannot be read without the password or recovery key (a long code saved when encryption was turned on). If you have neither, recovery is not realistic. Many people can find the key in a Microsoft account or a password manager.

3/5 · Take care
Success odds: Varies

Wrong resets or an erase on a hardware-encrypted stick can destroy the key and make the data permanently unreadable.

✋ Stop! Don't do this first

  • Do not reset the drive or keep guessing its PIN. Many keypad drives wipe themselves after a set number of wrong tries.
  • Do not format it to get access. That erases the data.
  • Do not use tools that claim to crack or guess encryption.

Your steps

0 of 6 done
  1. Show me how
    1. Plug the drive in. Windows: a padlock on the drive icon in File Explorer means BitLocker To Go.
    2. A drive with a keypad on its case uses hardware encryption.
    3. A drive holding a program or file called VeraCrypt uses VeraCrypt.
    4. Check the drive's label or box for a vendor name and look up its manual.

    Guide: Data recovery glossary for beginners

  2. Show me how
    1. BitLocker: go to aka.ms/myrecoverykey (it opens account.microsoft.com/devices/recoverykey) on any device and sign in with your Microsoft account. Also check any work or school account.
    2. Look for a printout, or a text file on another drive or in email.
    3. A BitLocker key is 48 digits in 8 groups.
    4. Match the key ID on the lock screen to the one shown online.
  3. Show me how
    1. Search your password manager for the drive name, BitLocker or VeraCrypt.
    2. Search email and notes for 'recovery key'.
    3. Check old documents and sticky notes.
  4. Show me how
    1. Plug the drive into a working computer.
    2. Windows (BitLocker): double-click the drive, click More options > Enter recovery key, type it and click Unlock.
    3. VeraCrypt: open the VeraCrypt app, click Select Device, pick the drive, click Mount and enter the password.
    4. Copy the files to another drive.
  5. Show me how
    1. You need a second drive with free space at least as big as the USB drive. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the USB drive's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the USB drive.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/usb.img /media/ubuntu/DEST/usb.map. Replace sdX with the USB drive's name and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the USB drive (the source), the second is where the copy goes. Swapping them erases the USB drive.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  6. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/usb.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Point TestDisk or PhotoRec at the unlocked drive or image, choose Analyse and Quick Search, and copy files to another drive.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Can I recover files from a locked USB without the password?

Realistically no. Good encryption cannot be bypassed, and anyone who promises otherwise should be treated with caution.

Where is my BitLocker key stored?

Often in your Microsoft account online, in a work or school account, on a printout or in a file you saved earlier.
