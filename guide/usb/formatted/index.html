🔌 USB flash drive · 🧹 Accidentally formatted

Recover Files from a Formatted USB Drive

A quick format only wipes the file list (the index of what is stored where), so much of the data is usually still on the USB drive. A full format on Windows Vista and later writes zeros over the whole drive, and that data is gone for good. Recovery works best if you have not copied anything new onto it.

2/5 · Low risk
Success odds: Varies

The scans are safe when run on a copy, but saving new files or formatting again reduces what can come back.

✋ Stop! Don't do this first

  • Do not copy new files onto the drive. They overwrite old ones.
  • Do not format it again or change its file system (the way it is organized).
  • Do not install recovery software onto the USB drive.

Your steps

0 of 6 done
  1. Show me how
    1. Windows: click the small arrow near the clock, click the USB icon and choose Eject. Mac: right-click the drive icon > Eject.
    2. Do not open, rename or save anything on it.
    3. If you remember choosing 'Quick Format' (Windows) or 'Erase' (Mac), the odds are better. Note that for later.
  2. Show me how
    1. You need a second drive with free space at least as big as the USB drive. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the USB drive's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the USB drive.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/usb.img /media/ubuntu/DEST/usb.map. Replace sdX with the USB drive's name and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the USB drive (the source), the second is where the copy goes. Swapping them erases the USB drive.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

  3. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/usb.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Choose Analyse, then Quick Search. If a partition appears, press p to list its files, then c to copy them to a different drive.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

  4. Show me how
    1. Open PhotoRec (a free tool that searches for file contents instead of file names; it comes with TestDisk). Windows: in the unzipped TestDisk folder, right-click qphotorec_win.exe and choose Run as administrator (this version has buttons). Linux live USB: type sudo apt install testdisk if you have not yet, then sudo photorec /media/ubuntu/DEST/usb.img to search your image. Mac: brew install testdisk, then sudo photorec. The text version uses the arrow keys and Enter.
    2. Pick the drive or image from the list (text version: then choose Proceed), then the partition, or the Whole disk line if unsure. When asked for the file system, pick Other (the window version calls it FAT/NTFS/HFS+/ReiserFS/...) unless it was a Linux drive (ext2/ext3/ext4). Choose Free for deleted files, or Whole for formatted, RAW or damaged drives.
    3. Click File Formats and untick types you do not need to save time. Some names differ from the file endings: keep jpg and png for photos, mov for MP4 and MOV videos, pdf, and zip for DOCX and XLSX. Text version: choose File Opt before Search, press s to untick everything, tick types with the Space bar, then press q to go back. Skipping this is also fine.
    4. Choose where to save results: a folder on a different drive, never the USB drive itself. Window version: click Browse. Text version: after Search it shows a list of folders; move to /media/ubuntu/DEST with the arrow keys and Enter, then press C.
    5. Window version: click Search. It can take hours. Leave the computer on until it says it has finished.

    Guide: How to use PhotoRec to recover photos and files

  5. Show me how
    1. Pick a folder on your computer's main drive or another external drive.
    2. Check there is enough free space. Windows: open This PC. Mac: right-click the drive > Get Info.
    3. Never choose the USB drive or the image file as the destination.
  6. Show me how
    1. Open the recovered folder. PhotoRec makes recup_dir.1, recup_dir.2 and so on.
    2. Windows: click Sort by > Type. Mac: View > as List.
    3. Open a few files of each type.
    4. If most are broken or blank, the drive was probably fully formatted or heavily reused.
Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Is a quick format recoverable?

Often yes. A quick format clears the file list but leaves most of the data in place until it is overwritten.

Does a full format erase everything?

On Windows Vista and later, yes: a full format writes zeros over the drive, so the old data cannot come back. Quick formats are often recoverable.
