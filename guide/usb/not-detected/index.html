🔌 USB flash drive · 🔍 Not detected / not showing up

USB Flash Drive Not Detected or Not Showing

A USB drive may not appear because of a bad port, a missing drive letter, damaged files, a worn connector or a failed controller (the small chip that runs the drive). Many cases are simple to check. Real hardware failure is harder and often needs a specialist.

3/5 · Take care
Success odds: Varies

Basic checks are safe, but forcing a damaged connector or soldering without experience can break the drive for good.

✋ Stop! Don't do this first

  • Do not click Format if Windows offers it. That wipes the file list.
  • Do not keep bending or wiggling the plug.
  • Do not use heat, glue or a soldering iron on it.

Your steps

0 of 6 done
  1. Show me how
    1. Unplug the drive and plug it into a different USB port, ideally on the back of a desktop.
    2. Do not use a USB hub or extension cable for this test.
    3. Try a different computer.
    4. If a window offers to format or scan, click Cancel.
  2. Show me how
    1. Windows: right-click the Start button and choose Disk Management. Mac: press Cmd+Space, type Disk Utility and press Enter, then click View > Show All Devices.
    2. Look for a drive of the right size. A drive with no letter, or labelled RAW or Unallocated, may still hold your files.
    3. Do not click Initialize, Format or Delete Volume. Just write down what you see.
    4. If nothing of the right size appears, go to the next step.

    Guide: Data recovery glossary for beginners

  3. Show me how
    1. Unplug the drive and hold it in good light.
    2. Look at the metal plug for bends, cracks or a wobble where it joins the case.
    3. Gently check if the plug moves. If it does, stop.
    4. Leave any soldering repair to a repair shop or lab.
  4. Show me how
    1. You need a second drive with free space at least as big as the USB drive. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the USB drive's name. Linux: type lsblk and match it by size (it looks like /dev/sdb). Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -d /dev/sdX /mnt/backup/usbdrive.img /mnt/backup/map.log replacing sdX and the folder with yours. The first path is the USB drive (the source), the second is where the copy goes. Swapping them erases the USB drive.
    6. Wait until it says it is finished. Keep the map.log file: it lets you stop and resume. Work only on an image file from now on.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  5. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: unzip the download from cgsecurity.org and double-click testdisk_win.exe. Mac or Linux: in Terminal type sudo testdisk.
    2. If you made an image, open it by typing testdisk image.img (Windows: run this in Command Prompt from the TestDisk folder). Otherwise choose the drive from the list with the arrow keys and press Enter.
    3. Choose Create (log file), then pick the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Choose Analyse, then Quick Search. If a partition shows, press p and copy files to another drive. If not, run PhotoRec on the image.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it yet.

  6. Show me how
    1. Decide how valuable the files are. If they cannot be replaced, stop experimenting.
    2. Search for data recovery labs near you. Look for a free evaluation and a 'no data, no fee' promise.
    3. Describe your exact problem and ask for a price range before you send anything.
    4. Pack the device in an anti-static bag or bubble wrap and ship it only after you agree on terms.

Questions people ask

Why does my USB drive show 0 bytes?

The controller often cannot read the memory chip properly. This is usually a hardware fault that software cannot fix.

Can a broken USB plug be fixed?

Sometimes, by soldering on a new connector, but it takes skill and a slip can destroy the data. Leave it to a repair shop or lab.
