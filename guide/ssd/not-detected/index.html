SSD (SATA and NVMe) · Not detected / not showing up

SSD Not Detected or Not Showing Up

If your computer cannot see the SSD, the cause could be a loose cable, a bad port, or a failed controller (the small chip that runs the SSD). A drive that appears with a strange name or tiny size, such as 'SATAFIRM S11', has a firmware (the SSD's built-in software) or controller failure and is not a home repair.

4/5 · High risk
Success odds: Varies

Simple cable and port checks are safe, but repeated power cycling or firmware tools can permanently damage a failing controller.

✋ Stop! Don't do this first

  • Do not run firmware flashing tools or 'repair' programs you found online. They can erase the data.
  • Do not keep turning the drive on and off hoping it comes back. Each power-up can wear a failing SSD further.
  • Do not open the drive or use heat or cold on it.

Your steps

0 of 7 done
  1. Show me how
    1. Shut the computer down and unplug it from the wall (laptop: also remove the battery only if it comes out easily).
    2. Desktop or laptop with an M.2 or SATA SSD: unplug the cable or gently pull the SSD out of its slot, then push it back in firmly.
    3. Try a different SATA cable, a different port, or a USB enclosure (a small case that turns an SSD into a USB drive).
    4. If you can, plug it into a second computer.
  2. Show me how
    1. Restart and tap the setup key as it starts (usually F2, Del, F10 or Esc, shown on the first screen). Look for your SSD's name in the drive list.
    2. Windows: right-click the Start button and choose Disk Management. If a window pops up asking to initialize the disk, click Cancel. Mac: press Cmd+Space, type Disk Utility and press Enter, then click View > Show All Devices.
    3. A drive that appears but has no drive letter may only need one. Do not change anything or click Initialize.
    4. Write down what name and size the SSD shows.

  3. Show me how
    1. Compare the name with the label printed on the SSD. A different name means a firmware fault.
    2. A size of 0 MB, 8 MB or a few MB is also a failure sign.
    3. If you see this, stop trying things and go to the professional step below.
    4. If the name and size look right, continue to the health check.
  4. Show me how
    1. Windows: download CrystalDiskInfo (free) from crystalmark.info, install it and open it. Linux live USB: in the Terminal type sudo apt install smartmontools, then sudo smartctl -a /dev/sdX (replace sdX with the SSD; an NVMe SSD is /dev/nvme0). Mac: type brew install smartmontools, then sudo smartctl -a disk0, using the disk name from diskutil list.
    2. Look at the big status word. Good means healthy. Caution or Bad means the SSD is in trouble.
    3. Also look for Reallocated or Available Spare, and Media Errors. Low spare or any media errors mean copy your files first.
    4. If it says Caution or Bad, skip any repair and go to making an image.

    Guide: How to check if a drive is healthy (SMART)

  5. Show me how
    1. You need a second drive with free space at least as big as the SSD. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the SSD's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). An NVMe SSD shows as nvme0n1. Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the SSD.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/ssd.img /media/ubuntu/DEST/ssd.map. Replace sdX with the SSD's name (an NVMe SSD shows as nvme0n1 instead, so you would type /dev/nvme0n1) and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the SSD (the source), the second is where the copy goes. Swapping them erases the SSD.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

  6. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/ssd.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Choose Analyse, then Quick Search. If your partition shows, press p to list files and c to copy them to another drive. If it does not, use PhotoRec on the image.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

  7. Show me how
    1. Decide how valuable the files are. If they cannot be replaced, do not experiment further.
    2. Search for data recovery labs near you and read their pricing page. Look for a free evaluation and a 'no data, no fee' promise.
    3. Ask them about your exact problem before you send anything. Do not pay a large fee up front.
    4. Pack the drive in an anti-static bag or bubble wrap and post it only after you agree on terms.

Questions people ask

Why does my SSD show up as SATAFIRM S11?

That is a known failure where the controller cannot load its firmware and falls back to a basic safe-mode name. Normal tools cannot reach your data.

Can I swap the circuit board to fix an SSD?

No. SSD controllers are tied to the data, often with built-in encryption. Even on hard drives a board swap needs the ROM chip moved, which is lab work.
