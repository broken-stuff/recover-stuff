⚡ SSD (SATA and NVMe) · 🧩 Corrupted / RAW / asks to format

Fix a Corrupted or RAW SSD Safely

Corruption means the drive's file index or partition information is damaged, even though the data may still be there. Sometimes it is a software issue, and sometimes the SSD is starting to fail. Work from a copy to avoid making it worse.

3/5 · Take care
Success odds: Medium

Letting Windows format or repair the drive, or running chkdsk, can overwrite the index information you need to recover your files.

✋ Stop! Don't do this first

  • Do not click Format when the system says the drive must be formatted.
  • Do not run chkdsk or any 'repair' prompt before making a copy.
  • Do not install recovery software onto the problem SSD.

🧑‍🔧 When to call a pro

If the SSD disconnects repeatedly, reports very few usable blocks, or the imaging stalls, stop and get professional help.

Questions people ask

Why does my SSD say it needs to be formatted?

The file system information is damaged or unreadable. Your files may still exist, so do not format.

Is it safe to run chkdsk on an SSD?

Not before you have a copy. Chkdsk changes the drive and can delete data it cannot fix.
