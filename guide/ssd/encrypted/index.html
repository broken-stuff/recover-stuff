⚡ SSD (SATA and NVMe) · 🔐 Encrypted or locked

Recover Data from an Encrypted SSD

If your SSD is protected with BitLocker (Windows), FileVault (Mac), VeraCrypt or built-in hardware encryption, the data is scrambled without the key. Without the password or recovery key (a long code made when encryption was turned on), recovery is not realistically possible. The good news is that keys are often saved somewhere you can find.

3/5 · Take care
Success odds: Varies

Wrong attempts, resets, or erasing the drive's encryption can make the data permanently unreadable.

✋ Stop! Don't do this first

  • Do not reset, secure erase or 'crypto erase' the SSD. That destroys the key and the data for good.
  • Do not reinstall the operating system over the encrypted drive.
  • Do not trust any site or service that promises to crack encryption.

Your steps

0 of 6 done
  1. Show me how
    1. Windows: open File Explorer. A padlock on the drive icon means BitLocker.
    2. Mac: open System Settings > Privacy & Security and look for FileVault, or open Disk Utility and look for 'Encrypted'.
    3. A file named something like .hc or a program called VeraCrypt means VeraCrypt.
    4. Hardware encryption: the drive asks for a password in the BIOS (the screen before Windows starts) or has a vendor program.

    Guide: Data recovery glossary for beginners

  2. Show me how
    1. BitLocker: go to aka.ms/myrecoverykey (it opens account.microsoft.com/devices/recoverykey) on any device and sign in with the Microsoft account used on that PC. Also check a work or school account.
    2. Look for a printout or a text file or USB stick saved earlier. A BitLocker key is 48 digits in 8 groups.
    3. FileVault: your Apple Account recovery on iCloud, or the key you wrote down. On newer Macs the SSD is built in and can only be unlocked inside that Mac.
    4. Match the first 8 characters of the key ID shown on the lock screen to the key you find.
  3. Show me how
    1. Search your password manager for BitLocker, FileVault, VeraCrypt, the drive name or the PC name.
    2. Search your email for 'recovery key' and 'BitLocker'.
    3. Check notes apps, cloud notes and old documents.
    4. Ask family or IT staff who may have set it up.
  4. Show me how
    1. Plug the SSD into a computer that supports the same encryption (any Windows 10 or 11 PC for BitLocker, Home editions included; a Mac for FileVault).
    2. Windows: double-click the drive in File Explorer, click More options > Enter recovery key, type the key and click Unlock.
    3. Mac: connect it and enter the password or recovery key in the window that appears.
    4. Copy the files to a different drive.
  5. Show me how
    1. You need a second drive with free space at least as big as the SSD. Plug it in and note its name.
    2. Windows: ddrescue runs from Linux, so follow the Live USB guide to start your PC from a Linux USB stick (a stick that starts a temporary Linux without touching your drive). When the Linux desktop appears, press Ctrl+Alt+T to open the Terminal and type sudo apt install gddrescue (the imaging guide explains what to do if it is not found). Mac: press Cmd+Space, type Terminal, press Enter, then type brew install ddrescue (needs Homebrew from brew.sh).
    3. Find the SSD's name. Linux: type lsblk -o NAME,SIZE,MODEL and match it by size (it looks like sdb, which you type as /dev/sdb). An NVMe SSD shows as nvme0n1. Mac: type diskutil list (it looks like /dev/disk4). Pick by size, never guess. Then open the destination drive in the Files app (Mac: Finder) so it is ready, but do not open the SSD.
    4. Mac only: type diskutil unmountDisk /dev/disk4 (use your number) so the Mac lets go of it. Do not click Initialize or Erase if a window pops up.
    5. Type sudo ddrescue -n /dev/sdX /media/ubuntu/DEST/ssd.img /media/ubuntu/DEST/ssd.map. Replace sdX with the SSD's name (an NVMe SSD shows as nvme0n1 instead, so you would type /dev/nvme0n1) and DEST with your destination drive's name (on Linux Mint the folder is /media/mint/ instead). On a Mac, use /dev/diskN as the first path and /Volumes/DEST/ for the other two. The first path is the SSD (the source), the second is where the copy goes. Swapping them erases the SSD.
    6. Wait until it says it is finished. Keep the .map file: it lets you stop and resume. Work only on an image file from now on.

    Guide: How to make an image (exact copy) of a driveGuide: How to make a Linux live USB (step by step)

  6. Show me how
    1. Open TestDisk (a free tool that finds lost partitions, meaning the sections of a drive, and deleted files). Windows: download it from cgsecurity.org, right-click the zip, choose Extract All, then right-click testdisk_win.exe and choose Run as administrator. Linux live USB: in the Terminal (Ctrl+Alt+T) type sudo apt install testdisk, then sudo testdisk. Mac: in Terminal type brew install testdisk, then sudo testdisk.
    2. If you made an image, start TestDisk on the image instead: type sudo testdisk /media/ubuntu/DEST/ssd.img (use your own folder and file name). Otherwise it lists your drives.
    3. Choose Create (log file), pick the drive or image with the arrow keys, choose Proceed, then accept the partition table type it suggests, usually Intel/PC or EFI GPT, and press Enter.
    4. Point TestDisk or PhotoRec at the unlocked volume or at the image. Choose Analyse and Quick Search, then copy files to a different drive.
    5. Use the arrow keys and Enter to move around and q to go back. TestDisk only changes anything if you choose Write, so do not choose it.

Mission complete! 🎉 Check your recovered files open properly, then back them up in two places.

Questions people ask

Can encrypted data be recovered without the key?

In practice, no. Modern encryption with a strong password cannot realistically be guessed or bypassed, so beware of anyone who says otherwise.

Where is my BitLocker recovery key?

Often in your Microsoft account online, a work or school account, a printout, or a file saved to a USB stick.
