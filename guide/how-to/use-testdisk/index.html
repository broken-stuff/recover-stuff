How to use TestDisk to copy files off a drive

TestDisk is a free tool that looks for lost partitions (the sections a drive is divided into) and can show the files inside them. It runs in a text screen, so you use the arrow keys and Enter instead of a mouse. For beginners, the safest way to use it is to look at files and copy them out.

Time needed: 20-60 minutes

You'll need

  • The drive, or better, an image file of it (see the image guide)
  • A different drive with enough free space to hold the files you recover
  • Windows, or a Linux live USB
  • Patience with a text-only screen

Step 1: Get TestDisk

TestDisk is free and made by CGSecurity.

  1. Windows: go to cgsecurity.org, open the TestDisk download page, and download the Windows zip file. Right-click it and choose Extract All. Open the extracted folder, right-click testdisk_win.exe and choose Run as administrator.
  2. Linux live USB: open the Terminal (Ctrl+Alt+T) and type: sudo apt install testdisk then press Enter. If it is not found, first run: sudo add-apt-repository universe
  3. To open it on Linux, type: sudo testdisk /path/to/drive.img to work on an image file. Or type: sudo testdisk and pick the drive from a list.
  4. On Windows, TestDisk lists the connected drives when it starts. If you want to use an image file there, open a command window in the folder and type: testdisk_win.exe drive.img

⚠️ Careful: Use the image file whenever you have one. Working on the real failing drive is riskier.

Step 2: Start a log and choose the disk

Navigation: arrow keys move, Enter confirms, q goes back or quits.

  1. At the first screen choose Create and press Enter. This makes a log file. It is safe.
  2. Select the disk or image you want to examine from the list, then choose Proceed and press Enter.
  3. Pick the partition table type. TestDisk usually guesses correctly. Most modern drives are Intel/PC (older, MBR) or EFI GPT (newer). Accept the highlighted choice and press Enter.

Step 3: Analyse and search

  1. Choose Analyse and press Enter. This shows the partitions it sees now.
  2. Choose Quick Search and press Enter. Wait while it scans. This is only reading.
  3. A list of found partitions appears. Highlight the one that looks right (the size and file system type are shown, such as NTFS or FAT32). If your files are not there, try Deeper Search later.

Step 4: Look at and copy your files

  1. With the partition highlighted, press P (the letter, not the Enter key). This lists the files inside it.
  2. Use the up and down arrows to move, and Enter to go into a folder. Use the .. entry at the top to go back.
  3. Highlight a file or folder you want and press C (copy). Files in red were deleted but may be recoverable.
  4. TestDisk will ask where to copy to. Navigate to a folder on the OTHER drive, not the one you are reading from, then press C again to confirm.
  5. Repeat for the other files. When done, press q repeatedly to leave.

⚠️ Careful: Always copy to a different drive. Copying onto the same drive can overwrite the very data you are trying to save.

What not to do

Avoid the Write option unless you understand it. It changes the partition table, which is the drive's map, and a wrong write can make recovery harder. As a beginner, only browse and copy files out. If the files do not appear, try PhotoRec next.

Questions people ask

I only see a blank list when I press P. What now?

The file system may be damaged. Go back, try Deeper Search, or switch to PhotoRec, which finds files without needing the partition to be healthy.

Does browsing files change the drive?

No. Analyse, Quick Search, listing files and copying all only read. Changes happen if you choose Write, so skip it.

Why do some files show in red?

Red means the file was deleted. It can often be copied out if the space has not been reused, but the contents may be partly damaged.
