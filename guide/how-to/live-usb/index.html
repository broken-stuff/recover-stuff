How to make a Linux live USB (step by step)

A live USB is a USB stick that holds a small, complete operating system. You start your computer from it instead of from your normal drive, so the problem drive is left alone. This is the safest way to run recovery tools on a computer that will not start.

Time needed: 30-60 minutes

You'll need

  • A working computer with internet (not the one with the problem drive, if you can avoid it)
  • An empty USB stick of 8 GB or more (everything on it will be erased)
  • About 6 GB of free space for the download
  • The computer you want to boot from the stick (a PC is best)

Step 1: Pick a Linux version

Ubuntu and Linux Mint are both free and friendly for beginners, and both have a live mode. Either one works for every guide on this site.

  1. Go to ubuntu.com/download/desktop (Ubuntu) or linuxmint.com/download.php (Linux Mint, choose the Cinnamon edition).
  2. Download the ISO file. An ISO is one large file that holds a full copy of the system. It is a few gigabytes, so it can take a while.
  3. Save it somewhere easy to find, such as your Downloads folder.

Step 2: Write the ISO to the USB stick

You need a small program that copies the ISO onto the stick in a way that makes it bootable. Just dragging the file onto the stick does not work.

  1. Plug in your empty USB stick.
  2. Windows or Mac: download balenaEtcher from etcher.balena.io and install it. Windows only: you can instead use Rufus from rufus.ie, which needs no install.
  3. In balenaEtcher, click Flash from file and pick the ISO. Click Select target and pick your USB stick. Check the size and name carefully. Click Flash.
  4. In Rufus, pick your USB stick under Device, click SELECT and choose the ISO, then click START. Accept the default options if it asks.
  5. Wait until it says it is finished, then close the program. Do not unplug the stick before then.

⚠️ Careful: Writing the live USB erases everything on that USB stick. Never choose the drive you are trying to recover as the target, and double-check the target before you click Flash or START.

Step 3: Open the boot menu

The boot menu lets you choose to start from the USB stick instead of your normal drive. The key to press differs by brand, and you must press it right as the computer powers on.

  1. Leave the live USB plugged in and shut the computer down fully.
  2. Turn it on and immediately tap the boot menu key over and over. Common keys: F12 (Dell, Lenovo), F9 (HP), F11 or F8 (various brands), Esc (some HP and ASUS models).
  3. If nothing happens, search the web for your computer's make and model plus 'boot menu key'. Your model name is on a sticker on the case.
  4. When a list of devices appears, use the arrow keys to pick the entry that mentions USB (it may show the stick's brand name), then press Enter.

⚠️ Careful: Some newer PCs need Secure Boot or Fast Boot adjusted in the BIOS settings. Ubuntu and Linux Mint normally start fine with Secure Boot on, so try the plain method first.

Step 4: Choose Try, never Install

A menu will appear after the logo. You want the live mode, which runs from the stick and leaves your drives unchanged.

  1. In Ubuntu, choose 'Try Ubuntu'. In Linux Mint, choose 'Start Linux Mint' from the first menu.
  2. Some versions show 'Try without installing' instead. That is the same thing.
  3. Wait for the desktop to appear. This can take a couple of minutes.
  4. Connect to Wi-Fi from the top-right corner menu if you need internet for downloading tools.

⚠️ Careful: Never click Install Ubuntu or Install Linux Mint. Installing writes to a drive and can erase the files you are trying to save.

Mac notes

Intel Macs can boot a live USB: shut down, turn on, and hold the Option key until the startup picker appears, then choose the USB entry (often called EFI Boot). Apple Silicon Macs (M1 and newer) do not boot Linux live USBs well, so borrow or use a PC if you can.

Questions people ask

Will a live USB change my computer?

No. It runs from the stick and from memory. Your drives stay untouched unless you choose to write to them, so only copy files out and do not format or install anything.

The computer still starts Windows. What now?

The boot menu key was probably pressed too late. Shut down fully and try again, tapping the key the moment you press power. Look up the exact key for your model if it still fails.

Can I use the same USB stick later?

Yes. Once the live USB is made, it keeps working until you write something else to it. Keep it labelled so you do not overwrite it by accident.
