How to use PhotoRec to recover photos and files

PhotoRec is a free tool that searches a drive for the raw contents of files and rebuilds them, even if the folders and names are gone. It works on formatted, damaged or deleted data. It does not change the drive it reads, but it saves what it finds to a folder you choose.

Time needed: 1-several hours, depending on drive size

You'll need

  • The drive, or better, an image file of it (see the image guide)
  • A different drive with plenty of free space for the results
  • Windows, or a Linux live USB
  • Time to sort results afterwards

Step 1: Get PhotoRec

PhotoRec comes in the same download as TestDisk, made by CGSecurity.

  1. Windows: from cgsecurity.org download the TestDisk and PhotoRec zip. Right-click it, choose Extract All, open the folder, and run qphotorec_win.exe as administrator (right-click, Run as administrator). This is the version with windows and buttons.
  2. Linux live USB: open the Terminal (Ctrl+Alt+T), type: sudo apt update then: sudo apt install testdisk and press Enter after each. If not found, run: sudo add-apt-repository universe first.
  3. Start it on Linux with: sudo photorec /media/ubuntu/DEST/drive.img (your own folder and file name) to use an image file, or: sudo photorec to pick a drive from a list.
  4. The Linux version is text-based. Use arrow keys to move and Enter to confirm.

Step 2: Choose the source and partition

  1. Pick the drive or image file you want to search (text version: then choose Proceed).
  2. Pick the partition from the list. If you are unsure, or the drive was formatted, choose the line for the whole disk (it may be called No partition or Whole disk).
  3. Choose the file system type. Pick Other for FAT, NTFS, exFAT and Mac drives (most Windows, USB and camera cards); in qphotorec it is labelled FAT/NTFS/HFS+/ReiserFS/... Pick ext2/ext3/ext4 for Linux drives. In the text version this question comes after you choose Search.

Step 3: Free or Whole

This choice changes what part of the drive gets searched.

  1. Choose Free to search only the unused space on a working partition. Use this for files you deleted by mistake.
  2. Choose Whole to search everything. Use this for drives that were formatted, reformatted, show as RAW, or will not open.

Step 4: Limit file types (optional but helpful)

Searching for every type of file takes longer and fills the results with junk. The File Opt menu lets you tick only what you need. Do this before you start the search.

  1. Open File Opt (in qphotorec, click File Formats; in the text version, choose File Opt from the menu at the bottom, next to Search).
  2. Untick everything (text version: press s), then tick only your file types (text version: Space bar). Some names differ from file endings: jpg and png for photos, cr2 or nef for camera RAW, mov for MP4 and MOV videos, pdf, doc for older Word and Excel files, and zip for DOCX and XLSX.
  3. Go back to the main screen.

Step 5: Set the destination and start

  1. Choose the folder where results will be saved. It must be on a different drive from the one you are searching, with lots of free space. In qphotorec, click Browse. In the text version, move through the folder list with the arrow keys and Enter; on a Linux live USB other drives are inside /media/ubuntu (Linux Mint: /media/mint).
  2. Click Search (text version: when you are inside the right folder, press C).
  3. Wait. A large drive can take many hours. You can see the number of files found rising.

⚠️ Careful: Never save results onto the drive you are recovering from. It can overwrite the data you want.

Step 6: Sort the results

PhotoRec saves files into folders called recup_dir.1, recup_dir.2, and so on. The files have generic names such as f1234567.jpg, because the original names and folders are usually lost.

  1. Open the destination folder and look inside each recup_dir.
  2. Use your file manager's thumbnail view for photos, and sort by type or size.
  3. Delete obvious junk, such as tiny icons and thumbnails, and rename or move the files you want to keep.

Questions people ask

Why are my file names gone?

PhotoRec finds files by their contents, not by the folder records. Those records are what hold the names, so they are not available after a format or damage.

Do I need an image before running PhotoRec?

It is strongly recommended if the drive is failing, because PhotoRec reads the whole drive. For a healthy drive or a memory card it is usually fine to run directly.

It found far more files than I expected. Is that normal?

Yes. It also recovers old files that were deleted before and system files. Limiting file types and sorting by date or size helps.
